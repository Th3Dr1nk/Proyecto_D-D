## Descripción del Proyecto

Este proyecto es una simulación de combate por turnos basada en el universo de Dungeons & Dragons, desarrollada para la asignatura de Programación. El objetivo es demostrar el uso de la herencia y el polimorfismo en Java, enfrentando a un Guerrero y un Mago con mecánicas únicas (armadura y maná). Todo el desarrollo se ha gestionado mediante un flujo de trabajo profesional en Git, utilizando ramas independientes para cada componente.

<img src="https://media1.tenor.com/m/-RIx9zQFhlMAAAAd/sir-get-down-police.gif">

## Estructura del Proyecto

El código está organizado de forma modular para cumplir con los principios de limpieza y orden:

    Personaje: Clase base abstracta con los atributos fundamentales.

    Guerrero: Subclase con lógica de reducción de daño por armadura.

    Mago: Subclase con gestión de maná y ataques mágicos potenciados.

    App: Clase principal que orquestra el duelo y muestra el log del combate por consola.

## Observaciones del codigo 

Compatibilidad: Se ha evitado el uso de caracteres especiales como la "ñ" en el código (usando damage en lugar de daño) para prevenir errores de compilación.

Encapsulación: Todos los atributos están protegidos y se acceden mediante métodos, garantizando la seguridad de los datos de cada luchador.

Gestión de Binarios: Se ha configurado el entorno para que los archivos .class no ensucien el repositorio, centrándonos solo en el código fuente.
